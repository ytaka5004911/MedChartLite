# MedChart Lite

JS + HTML + CSSだけでうごく、でんしカルテふうのがくしゅう・デモアプリです。

## おもなきのう
- かんじゃとうろく・へんしゅう・さくじょ
- かんじゃけんさく
- しんりょうきろくのついか・えつらん・さくじょ
- SOAPにちかい「しゅそ / げんびょうれき / しょけん / ひょうか・しんだん / ほうしん・けいかく」
- バイタルきろく
- しんりょうりれきをあたらしいじゅんにひょうじ
- JSONバックアップのかきだし・よみこみ
- IndexedDBによるブラウザないのえいぞくほぞん

## きどう
index.html をブラウザでひらいてください。

## じゅうよう
これは「でんしカルテふうUI」のがくしゅう・デモようです。
じっさいのかんじゃのこじんじょうほう・しんりょうじょうほうをほぞんするようとにはつかわないでください。

じつうんようには、にんしょう・けんげんかんり、サーバーがわDB、つうしんのあんごうか、かんさログ、バックアップ/ふっきゅう、アクセスせいぎょ、データほじポリシーなどがひつようです。
