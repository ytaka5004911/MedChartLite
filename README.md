# MedChart Lite

JS + HTML + CSSだけで動く、電子カルテ風の学習・デモアプリです。

## 主な機能
- 患者登録・編集・削除
- 患者検索
- 診療記録の追加・閲覧・削除
- SOAPに近い「主訴 / 現病歴 / 所見 / 評価・診断 / 方針・計画」
- バイタル記録
- 診療履歴を新しい順に表示
- JSONバックアップの書き出し・読み込み
- IndexedDBによるブラウザ内の永続保存

## 起動
index.html をブラウザで開いてください。

## 重要
これは「電子カルテ風UI」の学習・デモ用です。
実際の患者の個人情報・診療情報を保存する用途には使わないでください。

実運用には、認証・権限管理、サーバー側DB、通信の暗号化、監査ログ、バックアップ/復旧、アクセス制御、データ保持ポリシーなどが必要です。
